# صفحهٔ «همهٔ هنرمندان» — فهرست الفبایی خواننده‌ها

**آدرس روی سایت:** `https://ahangban.ir/singers/`
**فایل اصلی:** `artist-template.php` (ریشهٔ پوشهٔ قالب فعال)
**فایل دوم (فقط استایل):** `style.css` — یک بلوک در **انتهای** فایل
**پیش‌نمایش بدون نصب:** `cover-post/preview/artists.html` (با مرورگر باز کنید؛ جست‌وجو و نوار حروف در آن کار می‌کند)
**گزارش تشخیصی:** `https://ahangban.ir/singers/?ab_artists_diag=1` (فقط با حساب مدیر)

> ⚠️ این تغییر **هیچ ربطی به ثبت تاکسونومی و مسیریابی ندارد**: نه `register_taxonomy`، نه `rewrite`، نه هوک سراسری. اگر فایل را بردارید، قالب قبلی دقیقاً مثل قبل کار می‌کند. فقط روی همان برگه‌ای اثر دارد که قالبش «خواننده ها» انتخاب شده است.

---

## ۱) اول کدام فایل؟ (جواب کوتاه)

| ترتیب | فایل | کار |
|---|---|---|
| ۱ | `artist-template.php` | همان فایلی که صفحهٔ `/singers/` را می‌سازد. **فقط این یکی برای فهرست هنرمندان کافی است.** |
| ۲ | `style.css` | بلوک شمارهٔ ۱۵ در انتهای فایل (کارت‌ها، نوار حروف، حالت شب، موبایل). بدون این، صفحه کار می‌کند ولی زشت است. |

**چطور مطمئن شویم همین فایل است؟** دو راه:
1. پیشخوان → برگه‌ها → برگهٔ مربوط به «همهٔ هنرمندان» → جعبهٔ «ویژگی‌های برگه» → «قالب» باید روی **خواننده ها** باشد. در وردپرس نام فایل ذخیره می‌شود، پس تا وقتی اسم فایل `artist-template.php` بماند، این انتخاب به‌هم نمی‌خورد.
2. گزارش تشخیصی: `?ab_artists_diag=1` را باز کنید؛ خط «فایل قالب در حال اجرا» مسیر فایل را نشان می‌دهد.

## ۲) چه چیزی به صفحه اضافه شد؟

| # | قابلیت | قبل | حالا |
|---|---|---|---|
| ۱ | **ترتیب الفبای فارسی** | `orderby => name` (ترتیب دیتابیس؛ ی/ي و ک/ك جدا می‌شدند) | مرتب‌سازی واقعی فارسی: ی/ي، ک/ك، آ/أ/إ/ا، ة/ۀ/ه، حرکات و کشیده و نیم‌فاصله یکسان می‌شوند |
| ۲ | **گروه‌بندی حرفی + نوار حروف الفبا** | نداشت | ۳۲ حرف الفبا؛ حرف‌های خالی کم‌رنگ، هر حرف یک بخش با لنگر `#letter-ب` و شمارش |
| ۳ | **جست‌وجوی زنده** | نداشت | بدون درخواست به سرور، با نرمال‌سازی فارسی (تایپ «محسن يگانه» هم «محسن یگانه» را پیدا می‌کند) |
| ۴ | **ترتیب بر اساس تعداد آهنگ** | نداشت | لینک «پرتعدادترین» (`?sort=songs`) |
| ۵ | **فیلتر حرف با آدرس مستقل** | نداشت | `?letter=ب` — قابل اشتراک‌گذاری، قابل ایندکس، بدون جاوااسکریپت هم کار می‌کند |
| ۶ | **تعداد آهنگ هر خواننده** | نداشت | نشان (badge) روی کارت + خط آمار «۱۲۳ خواننده · ۴۵۶ آهنگ» |
| ۷ | **سرعت** | دو کوئری `get_terms` + متای هر ترم یکی‌یکی | یک کوئری + `update_termmeta_cache` (تصویرها با یک کوئری خوانده می‌شوند) |
| ۸ | **سرتیتر درست** | `<h3>لیست هنرمندان</h3>` | `<h1>` واقعی + یکتا برای هر آدرس (`… — حرف «ب»`) |
| ۹ | **سئو / هوش مصنوعی** | نداشت | متن یکتای توضیح + `ItemList` JSON-LD (تا ۲۰۰ مورد) |
| ۱۰ | **کارت‌ها** | تصویر ۲۰۰×۲۰۰ بدون lazy | `loading="lazy"`، `decoding="async"`، `srcset` وقتی تصویر از کتابخانهٔ رسانه باشد، افکت ملایم با hover |
| ۱۱ | **حالت‌های خالی/خطا** | صفحهٔ خالی | پیام «خواننده‌ای پیدا نشد»، پیام «خواننده‌ای ثبت نشده»، و پیام فنی فقط برای مدیر |
| ۱۲ | **صفحه‌بندی** | ۱۸ خواننده در هر صفحه، همیشه | فقط وقتی تعداد خواننده‌ها از ۱۲۰۰ بیشتر شود (سقف قابل تغییر) |
| ۱۳ | **حالت شب و موبایل** | نداشت | از متغیرهای `--ab-*` استفاده می‌کند؛ پس حالت شب خودکار درست می‌شود |

## ۳) کدوم قسمتِ `artist-template.php` چیست؟ (نقشهٔ خط‌به‌خط)

| خط‌ها | بخش | توضیح |
|---|---|---|
| ۱–۲۴ | سرصفحهٔ قالب | `Template Name: خواننده ها` — **دست نزنید**، همین باعث می‌شود وردپرس این فایل را برای برگه بشناسد |
| ۲۵–۲۸ | محافظ | `ABSPATH` |
| ۲۹–۴۷ | ۰) تنظیم‌ها | فقط همین جدول را برای تغییر عددها دست بزنید (تاکسونومی، پنهان‌کردن خوانندهٔ بی‌آهنگ، سقف‌ها، روشن/خاموش‌کردن جست‌وجو و نوار حروف) |
| ۴۸–۱۴۳ | ۱) توابع کمکی | نرمال‌سازی فارسی، کلید مرتب‌سازی، تصویر کارت (`aimg2`) |
| ۱۴۴–۱۷۷ | ۲) الفبا و آدرس‌ها | `?letter=` و `?sort=` + `noindex` برای صفحه‌های مرتب‌شده |
| ۱۷۸–۲۴۳ | ۳) گزارش تشخیصی | با `?ab_artists_diag=1` (فقط مدیر) |
| ۲۴۴–۳۷۳ | ۴) داده | یک `get_terms`، مرتب‌سازی در PHP، فیلتر حرف، گروه‌بندی، شمارش |
| ۳۷۴–۴۱۱ | ۵) سرتیتر | ساخت `<h1>` و لینک‌های ترتیب/حروف |
| ۴۱۲–۵۸۵ | ۶) نمایش | `get_header` + جست‌وجو/آمار + نوار حروف + بخش‌ها + کارت‌ها + صفحه‌بندی + «بازگشت به بالا» |
| ۵۸۶–۶۱۵ | ۷) داده‌ساختاریافته | `ItemList` (اسکیمای گوگل) |
| ۶۱۷–۶۹۶ | ۸) اسکریپت | جست‌وجوی زنده + هایلایت حرف فعال (۴۰ خط، بدون کتابخانه) |
| ۶۹۸ | پایان | `get_footer( '' )` |

## ۴) آدرس‌های مفید پس از نصب

| آدرس | کار |
|---|---|
| `/singers/` | فهرست کامل، گروه‌بندی‌شده بر اساس حروف الفبا |
| `/singers/?letter=ب` | فقط خواننده‌های حرف «ب» (قابل اشتراک‌گذاری و ایندکس) |
| `/singers/?sort=songs` | ترتیب بر اساس تعداد آهنگ (این آدرس `noindex` می‌شود؛ محتوای تکراری نیست) |
| `/singers/?letter=ب&sort=songs` | هر دو با هم |
| `/singers/?ab_artists_diag=1` | گزارش تشخیصی برای مدیر |

## ۵) تنظیم دلخواه (بدون تغییر منطق)

```php
// در myfunctions.php یا افزونهٔ کوچک خودتان
add_filter( 'javanseda_artists_config', function ( $cfg ) {
	$cfg['hide_empty']  = false; // خواننده‌های بدون آهنگ هم نمایش داده شوند
	$cfg['show_counts'] = false; // نشان تعداد آهنگ روی کارت‌ها حذف شود
	$cfg['max_terms']   = 2000;  // سقف قبل از رفتن به حالت صفحه‌بندی
	$cfg['show_search'] = false;
	return $cfg;
} );
```

تصویر هر خواننده از همان فیلد موجود قالب (`aimg2` در تاکسونومی `singer`) خوانده می‌شود؛ اگر خالی باشد تصویر پیش‌فرض `images/def-singer.webp` استفاده می‌شود.

## ۶) نصب و تست

1. از `artist-template.php` فعلی روی هاست یک نسخهٔ پشتیبان بگیرید (`.bak`).
2. فایل جدید را در **ریشهٔ پوشهٔ قالب فعال** جای‌گزین کنید (همان‌جایی که `single.php` است، دسترسی `644`).
3. بلوک CSS انتهای `style.css` را اضافه کنید (یا کل `style.css` جدید را بگذارید).
4. کش/CDN را پاک کنید.
5. `/singers/` را باز کنید و این‌ها را ببینید: نوار حروف، گروه‌بندی، شمارش، جست‌وجو، لینک «پرتعدادترین».
6. یک حرف را کلیک کنید (`?letter=ب`) و یک نام را در جعبهٔ جست‌وجو تایپ کنید.

**بازگشت به عقب:** فایل `.bak` خودتان را برگردانید، یا از `artifacts/restore-original-files.zip` استفاده کنید (نسخهٔ اصلی `artist-template.php` + `myfunctions.php`).
اگر فقط بلوک CSS را نمی‌خواهید، همان بخش ۱۵ را از انتهای `style.css` حذف کنید؛ صفحه با ظاهر ساده ولی سالم کار می‌کند.

## ۷) محدودیت‌ها (صادقانه)

- تست روی وردپرس زندهٔ شما انجام نشده؛ همهٔ بررسی‌ها ساختاری است (تجزیهٔ PHP، توازن CSS، اجرای لوکال پیش‌نمایش با HTTP 200).
- تعداد نهایی خواننده‌ها و اینکه همه‌شان تصویر دارند را نمی‌دانم؛ اگر تعداد از ۱۲۰۰ بیشتر شد، صفحه خودکار به حالت صفحه‌بندی می‌رود.
- اگر نام‌ها با فاصله یا پیشوند نادرست ثبت شده باشند، مرتب‌سازی همان چیزی را نشان می‌دهد که در نام ذخیره شده است.

## ۸) قدم بعدی

**صفحهٔ اختصاصی هر خواننده** (`taxonomy-singer.php`): مرتب‌سازی آهنگ‌ها، سرتیتر پروفایل با تصویر و تعداد، متن معرفی، داده‌ساختاریافته `Person`/`MusicGroup`، «خواننده‌های مشابه» و صفحه‌بندی برای خواننده‌های پرتعداد. جزئیات را جداگانه می‌فرستم و می‌گویم کدام قسمت کدام فایل است.
