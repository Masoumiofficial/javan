# صفحهٔ اختصاصی هر خواننده — `taxonomy-singer.php` (نسخهٔ ۲)

**آدرس نمونه:** `https://ahangban.ir/singer/mohsen-yeganeh/`
**فایل:** `taxonomy-singer.php` در **ریشهٔ پوشهٔ قالب فعال** (همان فایل قبلی، جای‌گزین می‌شود)
**استایل:** بخش **۱۶** در انتهای `style.css`

**گزارش تشخیصی (مدیر):** `/singer/<اسلاگ>/?ab_artist_diag=1`

## ۳) آدرس‌های جدید

| آدرس | کار |
|---|---|
| `/singer/<اسلاگ>/` | نمای پیش‌فرض: جدیدترین آثار |
| `/singer/<اسلاگ>/?sort=old` | قدیمی‌ترین اول |
| `/singer/<اسلاگ>/?sort=title` | مرتب‌سازی الفبایی نام آهنگ (فارسی‌خوان) |
| `/singer/<اسلاگ>/?ab_artist_diag=1` | گزارش تشخیصی (فقط مدیر) |

صفحه‌های `?sort=` با `noindex` علامت می‌خورند تا محتوای تکراری ساخته نشود.

## ۴) تنظیم دلخواه

```php
add_filter( 'javanseda_artist_page_config', function ( $cfg ) {
	$cfg['show_sort']     = false; // نوار ترتیب نمایش داده نشود
	$cfg['show_related']  = false; // «خواننده‌های مشابه» حذف شود
	$cfg['related_limit'] = 12;    // حداکثر تعداد مشابه‌ها
	$cfg['json_ld_max']   = 50;    // سقف آیتم‌های اسکیما
	return $cfg;
} );
```

سقف تعداد نوشته‌های هر خواننده هم مثل قبل با `javanseda_artist_posts_limit` کنترل می‌شود (`-1` = همه).

## ۵) بیوگرافی خواننده از کجا می‌آید؟

از **توضیحات ترم** همان خواننده: پیشخوان ← نوشته‌ها ← **خواننده‌ها** ← روی نام خواننده بزن ← کادر «توضیحات». هر متنی که آنجا بنویسی:

1. زیر سرتیتر پروفایل با فرمت HTML مجاز نمایش داده می‌شود،
2. به‌صورت `description` داخل `MusicGroup` در داده‌ساختاریافته می‌آید،
3. برای گوگل و موتورهای هوش مصنوعی به‌عنوان معرفی همان خواننده خوانده می‌شود.

اگر خالی باشد، هیچ بخش خالی یا پیام اضافه‌ای نمایش داده نمی‌شود (طراحی ناقص به‌نظر نمی‌رسد).

## ۶) نصب و تست

1. از `taxonomy-singer.php` فعلی روی هاست پشتیبان بگیرید (`.bak`).
2. فایل جدید را در ریشهٔ پوشهٔ قالب فعال جای‌گزین کنید (دسترسی `644`).
3. بلوک CSS بخش **۱۶** انتهای `style.css` را اضافه کنید (یا کل `style.css` جدید را بگذارید).
4. کش/CDN را پاک کنید.
5. یک صفحهٔ خواننده را باز کنید: سرتیتر پروفایل، نوار ترتیب، مشابه‌ها و بخش‌های آهنگ را ببینید. `?sort=title` را هم تست کنید.
6. اگر نوشته‌ای نمایش داده نشد: `?ab_artist_diag=1` را باز کنید و مقدار `musics_type` نوشته‌ها را ببینید.

**بازگشت به عقب:** فایل قبلی را برگردانید، یا از `artifacts/restore-original-files.zip` استفاده کنید. بخش ۱۶ استایل بی‌اثر می‌ماند و می‌تواند بماند.

## ۷) محدودیت‌ها (صادقانه)

- تست روی وردپرس زندهٔ شما انجام نشده؛ بررسی‌ها ساختاری‌اند (تجزیهٔ PHP، توازن CSS، اجرای لوکال پیش‌نمایش با HTTP 200).
- «خواننده‌های مشابه» بر اساس نوشته‌های موجود ساخته می‌شود؛ اگر هر نوشته فقط یک خواننده داشته باشد، تعداد کمتری نشان داده می‌شود یا هیچ (بخش مخفی می‌ماند).
- مرتب‌سازی الفبایی به فیلد `song` و در نبودش به «عنوان نوشته» تکیه می‌کند؛ اگر عنوان‌ها با «دانلود آهنگ…» شروع شوند، ترتیب بر اساس همان عنوان است. پیشنهاد: فیلد `song` را پر نگه دارید.
- تاریخ «آخرین به‌روزرسانی» با `get_the_date` می‌آید، پس اگر افزونهٔ تاریخ شمسی دارید همان تاریخ شمسی نمایش داده می‌شود.
