## Compatibility identifiers intentionally retained

The following values appear in CSS classes, function/widget/class names, widget IDs, menu IDs, option keys, and/or the protected payload: `tarlanweb_*`, `rkianoosh_*`, `indpl`, `hty`, `siing_*`, `music*`, `singer`. They may be used by existing front-end CSS/JS, saved widgets/options or plugins. They were not bulk-renamed. New display metadata and text-domain are changed separately.
