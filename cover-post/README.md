# سه فایل جایگزین — نمایش خودکار «کاور پست» (تصویر شاخص) در توضیحات

این سه فایل، نسخهٔ اصلاح‌شدهٔ همان فایل‌های **اصلی قالب شما** (`javanseda` نسخهٔ ۳.۰، مطابق `javanseda.zip`) هستند. هیچ تغییر دیگری (رنگ‌بندی، نام قالب، Text Domain، یا اصلاحات امنیتی نسخهٔ TaranehYar) روی آن‌ها اعمال نشده است؛ فقط قابلیت خواسته‌شده اضافه شده تا جایگزینی بی‌خطر باشد.

فایل‌ها: `single.php` · `style.css` · `myfunctions.php`

## چه چیزی در هر فایل تغییر کرده؟

### ۱) `single.php` — تغییر اصلی
داخل `<div class="single_content_box">` و **قبل از** `<?php the_content(''); ?>` این بلوک اضافه شده است:

```php
<?php
$taranehyar_featured_size = 'large'; // 'large' | 'full' | 'thumb1' (640×360) | 'thumb2' (190×190)
if ( has_post_thumbnail() ) {
	?>
	<figure class="single_featured_image">
		<?php the_post_thumbnail( $taranehyar_featured_size, array( 'alt' => get_the_title(), 'title' => get_the_title() ) ); ?>
	</figure>
	<?php
} ?>
```

نتیجه: تصویر شاخص هر نوشته به‌صورت خودکار در ابتدای بخش توضیحات چاپ می‌شود و دیگر لازم نیست همان تصویر را دستی داخل متن توضیحات بگذاری. برای تغییر اندازه فقط همان متغیر را عوض کن.

### ۲) `style.css` — استایل
بلافاصله بعد از خط `.single_content_box{position: relative;}` این دو قاعده اضافه شده است:

```css
.single_featured_image{margin: 0 0 20px 0;text-align: center;}
.single_featured_image img{display: inline-block;max-width: 100%;height: auto;border-radius: 5px;}
```

### ۳) `myfunctions.php` — اختیاری و غیرفعال
در انتهای فایل یک بلوک اضافه شده که به‌صورت پیش‌فرض **خاموش** است و هیچ کاری نمی‌کند (فقط تعریف یک ثابت). با آن می‌توانی همان قابلیت را «سراسری» و بدون دست‌زدن به قالب فعال کنی:

```php
define( 'JAVANSEDA_COVER_IN_CONTENT', false ); // برای حالت سراسری: true
```

اگر آن را `true` کنی، فیلتر `the_content` کاور را خودکار به محتوای همهٔ نوشته‌ها اضافه می‌کند. در این حالت باید بلوک تصویر شاخص را از `single.php` برداری، وگرنه تصویر دو بار نمایش داده می‌شود.

> `add_theme_support( 'post-thumbnails' )` و اندازه‌های `thumb1..thumb4` از قبل در همین فایل بودند؛ نیازی به تغییر آن‌ها نبود.

## نصب

1. از فایل‌ها و دیتابیس سایت بکاپ بگیر.
2. در مسیر `wp-content/themes/<پوشهٔ قالب فعلی>` سه فایل `single.php`، `style.css` و `myfunctions.php` را با همین سه فایل جایگزین کن (از طریق فایل‌منیجر هاست یا FTP).
3. اگر از کش (افزونهٔ کش، Cloudflare، کش مرورگر) استفاده می‌کنی، کش را پاک کن تا `style.css` تازه بارگذاری شود.
4. یک نوشتهٔ آهنگ را باز کن و ببین کاور در بالای توضیحات آمده است.

## نکته‌ها

- نوشته‌های بدون تصویر شاخص هیچ چیز اضافه‌ای نمایش نمی‌دهند (تصویر جای‌گزین `nomusics.jpg` عمداً اینجا استفاده نشده است).
- اگر همان تصویر را قبلاً دستی داخل متن توضیحات گذاشته‌ای، از متن حذفش کن تا دو بار تکرار نشود.
- برای برگه‌ها هم می‌خواهی؟ همین بلوک را در `page.php` قبل از `the_content('')` بگذار.
- `alt` و `title` تصویر از عنوان نوشته خوانده می‌شود.
- این سه فایل روی وردپرس واقعی اجرا/آزمایش نشده‌اند (محیط تست PHP/WordPress در دسترس نیست)؛ فقط از نظر ساختار PHP بررسی شده‌اند. قبل از اعمال روی سایت اصلی، روی staging امتحان کن.
