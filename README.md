- `taranehyar/` — سورس قالب وردپرس با پوشهٔ نصب `taranehyar`.
- `javanseda.zip` — آرشیو ورودی اصلی، دست‌نخورده.
- `docs/BASELINE-AUDIT.md` — خط مبنای مخزن، معماری، شواهد و محدودیت‌ها.
- `docs/FEATURE-INVENTORY.md` — قابلیت‌های واقعاً مشاهده‌شده و وضعیت آن‌ها.
- `docs/LICENSING-AND-ATTRIBUTION.md` — شواهد مجوز، انتساب و موانع حقوقی.
- `docs/COMPATIBILITY.md` — وابستگی‌ها و وضعیت سازگاری.
- `docs/TEST-REPORT.md` — نتایج تست واقعی و موارد مسدود.
- `CHANGELOG.md` — تغییرات نسخهٔ 3.0.1 آزمون فنی.
- `artifacts/taranehyar-3.0.1-test-build.zip` — بستهٔ دریافت و آزمون؛ نصب/فعال‌سازی یا مجوز بازتوزیع آن تأیید نشده است.

## محدودیت‌های مهم

1. `taranehyar/functions.php` و `taranehyar/RTL_License_41d6c5f704e3a746.php` با ionCube محافظت شده‌اند. سورس آن‌ها رمزگشایی یا دور زده نشده است؛ بنابراین بخش بزرگی از راه‌اندازی، ثبت Hookها، مدل داده، بارگذاری Assetها و کد مجوز قابل بازبینی نیست. پیش‌درآمد قابل‌مشاهدهٔ `functions.php` در نبود ionCube Loader خطا چاپ کرده و با وضعیت 199 خارج می‌شود.
2. برای خود قالب، فونت‌ها و بسیاری از تصاویر/دارایی‌ها مدرک مجوز یا واگذاری حق بازتوزیع در مخزن وجود ندارد. مالکیت مخزن، مجوز استفاده و حق فروش/بازنشر یکسان نیستند. انتشار این شاخه به درخواست مالک مخزن انجام می‌شود و به‌تنهایی مجوزی ایجاد نمی‌کند.
3. PHP و WordPress در محیط تست نصب نیستند؛ فعال‌سازی قالب، دیتابیس، پنل مدیریت، پخش رسانه و مرورگر آزمایش نشده‌اند.

این یک **شاخهٔ آزمون فنی** است، نه انتشار رسمی یا محصول آمادهٔ فروش. پیش از استفاده، تغییر یا جابه‌جایی روی staging و پس از تأیید مجوزهای لازم اقدام کنید. جزئیات و شواهد در اسناد `docs/` آمده است.

## راهنمای آزمون در محیط مجاز

1. از فایل‌ها و دیتابیس سایت نسخهٔ پشتیبان بگیرید و ابتدا روی staging کار کنید.
2. افزونهٔ Advanced Custom Fields را بررسی کنید؛ چندین قالب مستقیماً از API آن استفاده می‌کنند.
3. ZIP آزمون را از مسیر **نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته** بارگذاری کنید یا پوشهٔ `taranehyar/` را در `wp-content/themes/` قرار دهید.
4. نبود ionCube Loader مانع اجرای فایل محافظت‌شدهٔ `functions.php` می‌شود؛ نسخهٔ Loader و PHP سازگار از مدارک موجود قابل تعیین نیست.
5. پیش از جابه‌جایی از قالب قدیمی، تنظیمات OptionTree، ابزارک‌ها، منوها و قالب‌های برگه را ثبت و روی staging مقایسه کنید. مهاجرت خودکار یا حفظ قطعی داده‌های وابسته به slug تأیید نشده است. قالب قبلی را تا پایان آزمون حذف نکنید.
